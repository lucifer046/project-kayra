# ── ONNX Runtime is deliberately NOT pinned here. `setup.py` owns it. ──────────────────────
#
# There are three mutually exclusive distributions - onnxruntime, onnxruntime-gpu and
# onnxruntime-directml - and they all install into the SAME `onnxruntime/` package directory.
# Listing one here would mean:
#
#   * on an NVIDIA machine, every `pip install -r requirements.txt` silently overwrites the GPU
#     build with the CPU one, and speech synthesis quietly stops using the GPU;
#   * two distributions claiming the same files, so uninstalling either breaks the other.
#
# `kokoro-onnx` above already declares `onnxruntime>=1.20.1`, so the CPU wheel arrives as a
# transitive dependency regardless. `setup.py::configure_speech_runtime` runs AFTER this file
# is installed and repairs the environment: it selects the right variant for the detected
# hardware, removes the conflicting ones, installs the matching NVIDIA CUDA/cuDNN runtime
# wheels, and then PROVES a CUDA session can initialize before claiming GPU support.
#
# The package name is `onnxruntime-gpu`; the Python import is and remains `import onnxruntime`.
# There is no module named `onnxruntime_gpu`.
#
# Run `python setup.py` rather than installing ONNX Runtime by hand.
